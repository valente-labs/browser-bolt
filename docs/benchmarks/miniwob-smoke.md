# Small browser-control smoke sample

This sample uses the official [MiniWoB++ v1.1](https://github.com/Farama-Foundation/miniwob-plusplus/releases/tag/v1.1) HTML at commit `a7658beb68e1d3572329e06734c5822bd284ddc8`. It checks four interaction types: `click-test`, `click-test-2`, `enter-text`, and `choose-list`, with seeds 1, 2, and 3. It is 12 attempts per controller, not an official MiniWoB++ aggregate or a reliability estimate.

Clone and check out the pinned commit, then serve its `miniwob/html` directory with `python local/miniwob_adapter.py --html-root /path/to/MiniWoB-plusplus/miniwob/html`. The adapter binds only to loopback. The task URLs are `http://127.0.0.1:8945/miniwob/<task>.html?seed=<seed>`. It starts the seeded episode, extends the 10-second human timer to 1,000,000 ms for slower controllers, and hides the changing reward display before observation. It does not inject answers, selectors, or task-specific behavior. Give each controller the same page and task instruction, and start elapsed time at its first request to act. Run one attempt per task and seed, without runner retries.

Score success from the page's own terminal state: `WOB_DONE_GLOBAL === true && WOB_RAW_REWARD_GLOBAL > 0`. Record the task, seed, model/route, elapsed time, provider timing, reward, and any failure. A controller that cannot read the raw state may use the terminal reward displayed by the task after the episode, but that is a different observation path and should be recorded. Do not use an agent's `DONE` response as the success oracle.

In our initial post-fix sample, the direct Cerebras route passed 12/12 and the one-key OpenRouter fallback passed 12/12. Earlier 11/12 runs exposed newline-wrapped exact text and ambiguous select-option labels; both failures remain part of the evidence. These are small local observations. They do not show that Browser Bolt is faster on arbitrary sites or isolate browser runtime from model latency. A Codex Chrome comparison uses a different decision model and therefore measures complete systems, not an equal-model browser harness race.
